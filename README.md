# 🚀 Intellivision

> AI-powered image enhancement and intelligent visual processing platform built using React, Django, and Deep Learning.

---

## ✨ Overview

Intellivision is a full-stack AI web application focused on image enhancement, super-resolution, and intelligent visual analysis. The project combines a modern React frontend with a Django backend and integrates deep learning models for high-quality image processing.

Designed with performance and scalability in mind, Intellivision provides a smooth and responsive experience for uploading, processing, and analyzing images using AI-powered techniques.

---

# ⚡ Features

* 🧠 AI-powered image enhancement
* 🔍 Super-resolution processing

* ⚛️ Modern React + Vite frontend
* 🐍 Django REST backend

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Adityagola003/IntelliVision.git
```

---

# 🔧 Backend Setup

## Navigate to backend

```bash
cd backend/backend
```

## Install dependencies

```bash
pip install -r requirements.txt
```

## Start Django server

```bash
python manage.py runserver
```

Backend will run on:

```text
http://127.0.0.1:8000/
```

---

# 🎨 Frontend Setup

## Open a new terminal

## Navigate to frontend

```bash
cd frontend
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

Frontend will run on:

```text
http://localhost:5173/
```
